# Xiangxin AIoT Agriculture Platform

> Project Case 03 / Smart Agriculture

A completed AIoT agriculture prototype that generates field signals, classifies crop operating state, creates work orders, and benchmarks edge deployment latency.

This is no longer just a portfolio placeholder. It is a runnable research prototype with deterministic public-safe data generation, implemented analysis logic, regenerated SVG figures, structured outputs, and smoke tests.

Repository: [https://github.com/richardchen99/xiangxin-aiot-agriculture](https://github.com/richardchen99/xiangxin-aiot-agriculture)

## Research Question

How can field observations, crop images, and agricultural knowledge become a practical operating loop for growers?

## Implemented Method Stack

Sensor Fusion · Edge Rules · Crop State Classification · Work Orders

## What Is Completed

- `scripts/run_pipeline.py` runs the complete project pipeline.
- `src/research_pipeline.py` contains the implemented modeling, scoring, retrieval, simulation, or classification logic.
- `data/raw/` stores deterministic public-safe input samples generated by the pipeline.
- `data/processed/` stores model-ready outputs and intermediate analysis tables.
- `results/metrics.json` stores generated evaluation metrics.
- `results/key_findings.md` stores the generated research interpretation.
- `docs/index.html` is a polished result page.
- `docs/figures/` contains regenerated SVG charts.
- `tests/test_pipeline_smoke.py` verifies the pipeline can regenerate expected outputs.

## Reproduce

```bash
python3 scripts/run_pipeline.py
python3 -m unittest discover -s tests
```

The project uses only the Python standard library. No private data, API key, paid dependency, or external dataset is required.

## Output Contract

After running the pipeline, the repository should contain:

```text
data/raw/
data/processed/
results/metrics.json
results/key_findings.md
docs/index.html
docs/figures/*.svg
```

## Public-Safe Boundary

All data and results are deterministic public-safe research artifacts. The project does not include credentials, private datasets, proprietary reports, personal records, or sensitive operational material.
